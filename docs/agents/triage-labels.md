# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use the corresponding tracker label whenever a skill names a triage role.

## Work labels

| Label | Meaning |
| --- | --- |
| backend | Business logic |
| design | Design work only |
| frontend | Design implementation and UI work |

Work labels describe scope and may accompany a triage label.
